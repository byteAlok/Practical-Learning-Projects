# Personal Portfolio 💻

> Deprecated personal portfolio website built with HTML, CSS, JavaScript, Tailwind CSS, GSAP, and EmailJS.

This repository contains an older version of my personal portfolio website. It was created to showcase my skills, projects, education, experience, and provide a simple way to get in touch.

> ⚠️ **Status: Deprecated**
>
> This version is no longer actively maintained and has been superseded by a newer portfolio.

🌐 **Live:** https://alokmaurya.netlify.app/

---

## ✨ Features

- Responsive portfolio design
- Mobile navigation
- About section
- Education & experience
- Skills showcase
- Project showcase
- Contact section
- Download CV option
- Smooth scrolling
- Scroll-based animations
- Interactive UI elements
- Email-based contact form

---

## 🎨 UI & Animations

The portfolio uses Tailwind CSS and custom JavaScript animations to create the visual experience.

- Tailwind CSS
- GSAP
- GSAP ScrollTrigger
- Font Awesome

GSAP and ScrollTrigger are used for custom page and scroll-based animations.

---

## 📧 Contact

The contact form uses **EmailJS** to send messages directly from the frontend without requiring a custom backend.

## 🚀 Run Locally

Since this is a static website, no backend or database is required.

```bash
git clone <repository-url>
cd <project-folder>
```

Open `index.html` in a browser or use a local development server such as VS Code Live Server.
