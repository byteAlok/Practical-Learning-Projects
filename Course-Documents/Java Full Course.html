📚 Java Standard Libraries – Full Developer Reference

1️⃣ Scanner (java.util.Scanner)

Purpose: Input from console or file

nextInt(), nextFloat(), nextBoolean()
Reads respective data types
next(), nextLine()
Reads string/token/line
hasNext(), hasNextLine()
Checks if input is available
useDelimiter(), useLocale()
Customize input parsing
close()
Close input resource
Scanner sc = new Scanner(System.in);
int age = sc.nextInt();
String name = sc.nextLine();

2️⃣ Arrays (java.util.Arrays)

Purpose: Utility class for array manipulation

sort(), binarySearch()
Sorting and searching
equals(), mismatch()
Comparison tools
fill(), copyOf(), copyOfRange()
Modify or duplicate arrays
toString()
Convert array to string
int[] nums = {5, 1, 3};
Arrays.sort(nums);
System.out.println(Arrays.toString(nums));

3️⃣ Math (java.lang.Math)

Purpose: Mathematical computations

abs(), max(), min()
Basic calculations
sqrt(), cbrt(), pow()
Roots and exponents
round(), ceil(), floor()
Rounding tools
log(), log10(), random()
Advanced math
double result = Math.pow(2, 3);
int max = Math.max(10, 20);

4️⃣ String (No import needed)

Purpose: Immutable text objects

charAt(), length(), substring()
Character access and slicing
equals(), contains(), startsWith()
Comparison tools
replace(), split(), matches()
Search & replace, regex
toLowerCase(), toUpperCase(), trim()
Formatting helpers
String s = "Hello Java";
System.out.println(s.substring(0, 5));

5️⃣ File Handling (java.io.*)

Purpose: Read/write text files

File
exists(), createNewFile(), delete()
FileWriter
write(), close()
BufferedReader
readLine(), close()
PrintWriter
println(), printf()
FileWriter fw = new FileWriter("data.txt");
fw.write("Hello");
fw.close();

6️⃣ Wrapper Classes

Purpose: Primitive to object and vice-versa

Integer, Double, Boolean, etc.
parseX(), valueOf(), toString(), MAX_VALUE
int x = Integer.parseInt("123");
String s = String.valueOf(456);

7️⃣ System Class (java.lang.System)

Purpose: Environment and I/O tools

System.in
Standard input (used with Scanner)
System.out
Print to console
System.err
Error messages
currentTimeMillis()
Timing/logging
exit(status)
Terminate app
gc()
Run garbage collection
System.out.println("Hello");
System.exit(0);

8️⃣ Exception Handling

Purpose: Safe error control

try { }
Wrap risky code
catch (Exception e)
Handle error
finally { }
Always run cleanup
throw, throws
Raise exceptions
try {
  int x = 10 / 0;
} catch (ArithmeticException e) {
  System.out.println("Divide by zero!");
}

9️⃣ Boolean in Java

Purpose: Logical control and truth value management

boolean primitive
Can store only true or false
Boolean.parseBoolean(String)
Converts string to primitive boolean
Boolean.valueOf(String)
Returns Boolean object from string
Boolean.compare(x, y)
Compares two booleans
Boolean.toString(boolean)
Converts boolean to string
Boolean constants
Boolean.TRUE, Boolean.FALSE
boolean isActive = true;
if (isActive) {
  System.out.println("Active!");
}

boolean flag = Boolean.parseBoolean("false");
String boolStr = String.valueOf(true);

System.out.println(true && false); // false
System.out.println(!true);         // false
