String in php :

	In php String is sequence of a character that can use to store and manipulate the text, Any thing is in double or single quotes that is string datatype in php.

		$str = "Alok Maurya" or 'Alok Maurya';

How to add(concate) to strings?
	We can use dot(.) symbol to add two strings.

Some important function in php?
	1. strlen() : this is used to count the length of string.
	2. trim() : this is used for remove any white space from start and end.
	3. str_replace() : this function replace some character with some other character from string.
	4. str_pos() : this function searches for a specific text within a string - if match is found then the function return the character position of the first match, if no match is found it will return false.
	5. explod() : this function split the string into array.

Function in php ?

	In parameterized function their are declare inside the bracket after the function name. A parameter is a value you passed to a function or static.
	
	We can passed the value of the variable at the time of calling the function.
